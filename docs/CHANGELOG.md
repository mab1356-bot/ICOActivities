# تغییرات این بسته

## تغییرات بازآرایی ساختار و بهبود تقویم (مبنای انتشار 4.3.2)
- انتقال CSS به `assets/css/app.css`.
- انتقال منطق اصلی JavaScript به `assets/js/app.js`.
- انتقال ثبت Service Worker به `assets/js/pwa.js`.
- افزودن فایل‌های جدید به precache در `sw.js`.
- نمایش تمام جزئیات اقدام در کارت‌های پنجره روز تقویم.
- حفظ نمایش جزئیات کامل در پنجره بازشونده نمای هفتگی.
- بهینه‌سازی گروه‌بندی اقدامات تقویم ماهانه بر اساس تاریخ.
- افزودن استایل واکنش‌گرا برای کارت جزئیات.
- تکمیل مستندات ساختار، معماری و انتشار.


## نسخه 4.3.2 — انتشار و نوسازی کش
- ارتقای نسخه برنامه و نسخه کش Service Worker به `4.3.2` و `Ver-4.3.2`.
- هماهنگ‌سازی شماره نسخه در تمام مستندات پروژه.
- محدود کردن پاک‌سازی کش‌های قدیمی به کش‌های دارای پیشوند `actbk-cache-` تا کش سایر برنامه‌های مستقر روی همان مبدأ حذف نشود.
- به‌روزرسانی راهنمای انتشار و سیاست افزایش نسخه.
