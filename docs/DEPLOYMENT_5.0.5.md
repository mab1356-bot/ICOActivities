# راهنمای انتشار نسخه ۵.۰.۵

## ۱. جایگزینی فایل‌ها

- از مخزن GitHub نسخه پشتیبان تهیه کنید.
- تمام فایل‌های بسته را با حفظ ساختار پوشه‌ها در مخزن بارگذاری کنید.
- فایل `config.js` فعلی را حفظ کنید؛ این فایل در بسته قرار نگرفته است.
- فایل `sw.js` این بسته نسخه ۵.۰.۵ است و باید همراه سایر فایل‌ها منتشر شود.

## ۲. پایگاه داده

نسخه ۵.۰.۵ به SQL جدید نیاز ندارد. اگر مهاجرت نسخه ۵.۰.۴ هنوز اجرا نشده است، ابتدا فایل `supabase/5.0.4_attendance_multiday_time_range.sql` را یک بار در Supabase اجرا کنید. مهاجرت‌های قبلی را دوباره اجرا نکنید.

## ۳. پاک‌سازی کش مرورگر

پس از انتشار، صفحه را آنلاین باز کنید و اجازه دهید Service Worker نسخه `Ver-5.0.5` نصب و فعال شود. اگر مرورگر نسخه قبلی را نگه داشت، از پنجره به‌روزرسانی برنامه یا ابزار پاک‌سازی داده‌های سایت مرورگر استفاده کنید.

## ۴. آزمون پس از انتشار

چک‌لیست `docs/TEST_PLAN_5.0.5.md` را اجرا کنید؛ به‌ویژه ستون شماره پرسنلی و ترتیب مرتب‌سازی در هر دو بخش خروجی CSV را بررسی کنید.
