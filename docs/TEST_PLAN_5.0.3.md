# چک‌لیست آزمون نسخه ۵.۰.۳

## حساب ویژه ۹۵۸۰۰۱
- [ ] با حسابی وارد شوید که پروفایل آن شماره پرسنلی ۹۵۸۰۰۱ است.
- [ ] در فرم ایجاد اقدام جدید، فرد شماره ۷۸۴۹۵ به‌صورت پیش‌فرض انتخاب‌شده باشد.
- [ ] انتخاب فرد ۷۸۴۹۵ را بردارید و فقط فرد دیگری را انتخاب کنید؛ ثبت باید موفق باشد.
- [ ] فرد ۷۸۴۹۵ و خود کاربر ۹۵۸۰۰۱ را هم‌زمان انتخاب کنید؛ ثبت باید موفق باشد.
- [ ] فقط خود کاربر ۹۵۸۰۰۱ را انتخاب کنید؛ ثبت باید موفق باشد.
- [ ] پس از بازنشانی فرم برای ثبت اقدام بعدی، فرد ۷۸۴۹۵ دوباره پیش‌فرض انتخاب شود.
- [ ] هنگام ویرایش یک اقدام موجود، شرکت‌کنندگان ذخیره‌شده حفظ شوند و پیش‌فرض جدید جایگزین آن‌ها نشود.
- [ ] در داده ذخیره‌شده، `createdBy` شناسه حساب ۹۵۸۰۰۱ باشد، حتی اگر شرکت‌کننده فقط ۷۸۴۹۵ باشد.

## سایر حساب‌ها و بخش‌ها
- [ ] با یک کاربر عادی دیگر وارد شوید؛ رفتار قبلی انتخاب اجباری خود کاربر بدون تغییر باشد.
- [ ] با مدیر/ادمین وارد شوید؛ رفتار قبلی انتخاب‌گر حفظ شود.
- [ ] تقویم و گزارش‌ها رفتار قبلی را داشته باشند.
- [ ] ماژول ثبت عدم حضور و ثبت رویداد شخصی هیچ تغییری نداشته باشد.
- [ ] شماره پرسنلی ۷۸۴۹۵ در جدول اشخاص موجود باشد؛ در غیر این صورت، انتخاب به حساب ۹۵۸۰۰۱ برمی‌گردد و پیام هشدار در کنسول ثبت می‌شود.
