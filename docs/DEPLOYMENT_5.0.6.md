# راهنمای انتشار نسخه ۵.۰.۶

1. از مخزن GitHub نسخه پشتیبان تهیه کنید.
2. تمام فایل‌های بسته را جایگزین نسخه قبلی کنید.
3. فایل `config.js` فعلی را حفظ کنید؛ در این بسته قرار نگرفته است.
4. `sw.js` همراه بسته را منتشر کنید؛ نسخه کش `actbk-cache-v5.0.6` و مقدار `Ver-5.0.6` است.
5. مهاجرت SQL جدید لازم نیست. مهاجرت‌های قبلی را مجدداً اجرا نکنید.
6. روی موبایل و دسکتاپ هر دو ماژول را از نظر انتخاب ساعت آزمایش کنید.
7. با حساب‌های عادی، مدیر، ادمین و سوپر ادمین منوها و عملیات را بررسی کنید.
8. امنیت نهایی داده‌ها همچنان باید با RLS و توابع سمت سرور Supabase اعمال شود.
