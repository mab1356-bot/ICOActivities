# تغییرات نسخه ۵.۰.۵

## خروجی داشبورد عدم حضور

- در بخش «خلاصه افراد» خروجی CSV، ستون شناسه نمایشی افراد با عنوان «شماره پرسنلی» ارائه می‌شود.
- در بخش «جزئیات روزانه» نیز شماره پرسنلی درج می‌شود.
- ردیف‌ها بر اساس شماره پرسنلی به‌صورت صعودی مرتب می‌شوند؛ رویدادهای هر فرد نیز بر اساس تاریخ شروع و سپس تاریخ پایان مرتب هستند.
- قالب CSV با BOM یونیکد حفظ شده تا در Excel حروف فارسی صحیح نمایش داده شوند.

## Service Worker

- فایل `sw.js` ارسالی کاربر در بسته ادغام شد.
- نسخه برنامه و کش به `actbk-v5.0.5` و `Ver-5.0.5` ارتقا یافت.
- منطق precache، پاک‌سازی کش‌های متعلق به همین برنامه، اولویت شبکه برای صفحات و فعال‌سازی کنترل‌شده نسخه منتظر حفظ شده است.
