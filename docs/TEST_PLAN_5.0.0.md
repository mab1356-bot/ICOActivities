# برنامه آزمون نسخه 5.0.0

## آماده‌سازی
- [ ] تهیه نسخه پشتیبان از Supabase.
- [ ] اجرای یکباره `supabase/5.0.0_modules_attendance.sql` (شامل داشبورد و سیاست نهایی RLS).
- [ ] تأیید فعال بودن RLS روی `app_modules`، `person_module_access` و `attendance_events`.
- [ ] تغییر دستی `CACHE_VERSION` در `sw.js` به `Ver-5.0.0` هنگام انتشار.

## درگاه مرکزی و نشست
- [ ] ورود با کاربر عادی، مدیر و سوپر ادمین.
- [ ] پس از ورود، درگاه مرکزی به‌جای ورود مستقیم به تقویم نمایش داده شود.
- [ ] کارت «ثبت فعالیت» ماژول قبلی را با تمام امکانات باز کند.
- [ ] کارت «ثبت عدم حضور» ماژول جدید را باز کند.
- [ ] جابه‌جایی بین دو ماژول بدون خروج و ورود مجدد انجام شود.
- [ ] پنل جابه‌جایی سریع از هر دو ماژول باز شود و ماژول اخیر/موردعلاقه را مستقیم باز کند.
- [ ] پیوند مشاهده همه ماژول‌ها به درگاه مرکزی برگردد.
- [ ] خروج از هر دو ماژول، نشست کل سامانه را ببندد.
- [ ] جستجوی ماژول، علاقه‌مندی‌ها و ماژول‌های اخیر کار کنند.

## مدیریت عنوان
- [ ] پنل مدیریت ماژول‌ها فقط برای سوپر ادمین نمایش داده شود.
- [ ] سوپر ادمین عنوان هر دو ماژول را تغییر دهد.
- [ ] عنوان جدید پس از بارگذاری مجدد برای همه کاربران نمایش داده شود.
- [ ] کاربر عادی و مدیر نتوانند عنوان را تغییر دهند (کنترل RLS نیز آزموده شود).
- [ ] سوپر ادمین بتواند دسترسی هر کارمند به هر ماژول را فعال/غیرفعال کند.
- [ ] دسترسی حساب‌های سوپر ادمین در ماتریس قابل غیرفعال‌سازی نباشد.
- [ ] کاربر پس از غیرفعال شدن دسترسی، کارت ماژول را نبیند و درخواست مستقیم REST به جداول آن ماژول نیز رد شود.

- [ ] ثبت مرخصی روزانه تک‌روزه و چندروزه.
- [ ] ثبت مرخصی ساعتی با ساعت شروع و پایان معتبر.

- [ ] ثبت مأموریت داخل استان و خارج استان.
