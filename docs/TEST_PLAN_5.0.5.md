# برنامه آزمون نسخه ۵.۰.۵

1. با حساب ادمین یا سوپر ادمین وارد ماژول «ثبت عدم حضور» شوید.
2. داشبورد را برای بازه‌ای که چند کارمند و چند رویداد دارد تولید کنید.
3. خروجی CSV را دریافت و با Excel باز کنید.
4. در بخش «خلاصه افراد» بررسی کنید ستون شناسه «شماره پرسنلی» باشد و مقدار آن شماره پرسنلی واقعی فرد باشد.
5. در بخش «جزئیات روزانه» نیز شماره پرسنلی را بررسی کنید؛ نام فرد نباید جای شماره پرسنلی در آن ستون قرار گرفته باشد.
6. بررسی کنید ترتیب افراد بر اساس شماره پرسنلی صعودی باشد.
7. برای هر فرد چند رویداد با تاریخ شروع متفاوت ثبت‌شده داشته باشید و مرتب‌سازی تاریخ شروع را در جزئیات روزانه بررسی کنید.
8. بررسی کنید تاریخ‌های روزانه داخل هر رویداد همچنان به ترتیب صعودی باشند و ساعت شروع/پایان و نوع روز کاری/غیرکاری مانند نسخه قبل حفظ شده باشد.
9. در ابزار توسعه مرورگر، فعال‌شدن Service Worker نسخه `Ver-5.0.5` و دریافت فایل‌های precache را بررسی کنید.
10. ورود، بارگذاری برنامه و جابه‌جایی بین دو ماژول را پس از فعال‌شدن Service Worker آزمایش کنید.

این چک‌لیست جایگزین آزمون عملی روی مخزن GitHub و پروژه واقعی Supabase نیست.
