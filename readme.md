# 📊 سیستم ثبت فعالیت ماهانه (Monthly Activity Registration)

وب‌اپلیکیشن (PWA) برای ثبت، پیگیری، برنامه‌ریزی و گزارش‌گیری فعالیت‌های پرسنل واحد کنترل و نظارت پروژه‌های سرمایه‌گذاری.

## ✨ ویژگی‌ها
- **احراز هویت امن (Supabase Auth)**: ورود با ایمیل ساختگی (`username@app.com`)، اجبار به تغییر رمز در اولین ورود.
- **نیازمند اتصال**: ثبت و ویرایش فقط آنلاین است. در صورت قطع اتصال، کاربران به صفحه لاگین هدایت می‌شوند.
- **همگام‌سازی یک‌طرفه (Pull)** با Supabase؛ داده محلی به عنوان کش استفاده می‌شود و هرگز روی داده سرور بازنویسی نمی‌شود.
- **سطوح دسترسی**: سوپر ادمین، ادمین، مدیر، کاربر (با RLS بومی دیتابیس).
- **تقویم ماهانه/هفتگی**، تعطیلات رسمی (کسر از ساعت چندروزه‌ها)، اقدامات «فقط برای من».
- **محل‌های برگزاری** قابل مدیریت توسط سوپر ادمین (جدول `locations`).
- جلوگیری از ثبت تکراری (شباهت ≥ ۴۰٪)، گزارش A4/Word/PowerPoint.

## 🚀 راه‌اندازی / ارتقا
1. **دیتابیس**: در Supabase فایل `migration_v3.0.0.sql` را اجرا کنید (ساخت توابع امن، RLS و ستون‌های جدید).
2. **تنظیمات Auth**: در داشبورد Supabase بخش Authentication:
   - گزینه **Confirm email** را خاموش کنید.
   - در بخش Hooks، تابع `custom_access_token_hook` را فعال کنید.
   - آدرس سایت (Site URL) و Redirect URL ها را تنظیم کنید.
3. **Edge Functions**: در بخش Edge Functions، دو تابع `setup-admin` و `create-user` را طبق مستندات Deploy کنید.
4. **کلاینت**: فایل `config.js` را با `SUPABASE_URL` و `SUPABASE_ANON_KEY` تنظیم کنید.
5. فایل‌ها را روی هاست (مثل GitHub Pages) آپلود کنید.
6. `CACHE_VERSION` را در `sw.js` افزایش دهید.
7. **اولین اجرا**: فرم «ایجاد حساب مدیر اصلی» ظاهر می‌شود. حساب خود را بسازید.

## ⚠️ قانون طلایی
با هر تغییر در `Activity.html`، `config.js` یا `sw.js`، حتماً `CACHE_VERSION` را در `sw.js` افزایش دهید. قالب ورژن: `اساسی.کلی.جزئی`.
