# 📊 سیستم ثبت فعالیت ماهانه (Monthly Activity Registration)

وب‌اپلیکیشن (PWA) برای ثبت، پیگیری، برنامه‌ریزی و گزارش‌گیری فعالیت‌های پرسنل واحد کنترل و نظارت پروژه‌های سرمایه‌گذاری.

## ✨ ویژگی‌ها
- **نیازمند اتصال**: ثبت و ویرایش فقط آنلاین است؛ در نبود اتصال فقط سوپر ادمین می‌تواند برای تهیهٔ پشتیبان وارد شود.
- **همگام‌سازی یک‌طرفه (Pull)** با Supabase؛ داده محلی هرگز روی سرور نوشته نمی‌شود.
- **سطوح دسترسی**: سوپر ادمین، ادمین، مدیر، کاربر.
- **احراز هویت امن**: ورود با توابع سرور، bcrypt، محدودیت تلاش، نشست ۱۲ ساعته، خروج پس از ۶۰ دقیقه بی‌فعالیتی.
- **تقویم ماهانه/هفتگی**، تعطیلات رسمی (کسر از ساعت چندروزه‌ها)، اقدامات «فقط برای من».
- **محل‌های برگزاری** قابل مدیریت توسط سوپر ادمین (جدول `locations`).
- جلوگیری از ثبت تکراری (شباهت ≥ ۴۰٪)، گزارش A4/Word/PowerPoint.

## 🚀 راه‌اندازی / ارتقا
1. در Supabase فایل `migration_v2.0.0.sql` را اجرا کنید (ساخت جدول‌ها و توابع امن).
2. `config.js` را با `SUPABASE_URL` و `SUPABASE_ANON_KEY` تنظیم کنید.
3. فایل‌ها را روی هاست (مثل GitHub Pages) آپلود کنید.
4. `CACHE_VERSION` را در `sw.js` افزایش دهید.
5. اولین اجرا: حساب «سوپر ادمین» ساخته می‌شود.

## ⚠️ قانون طلایی
با هر تغییر در `Activity.html`، `config.js` یا `sw.js`، حتماً `CACHE_VERSION` را افزایش دهید. قالب ورژن: `اساسی.کلی.جزئی`.
